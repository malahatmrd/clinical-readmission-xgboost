## Data Distribution Policy

Raw clinical data and patient-level derived data are not distributed through
this Git repository.

The repository excludes:

- raw clinical data
- patient-level interim datasets
- row-level Train/Validation/Test assignments
- row-level final Test predictions

Only aggregate metrics, source code, documentation, tests, figures, and
non-identifying research artifacts are intended for version control.
